# Use Cases

## Quick SQL Server health check

Run `HealthSummary.sql` to get a fast overview of CPU, blocking, missing indexes and storage indicators.

## Find expensive queries

Run `Expensive_Queries.sql` to identify costly cached queries by CPU, duration, reads and writes.

## Investigate missing indexes

Run `Missing_Indexes.sql` to find high-impact missing index candidates.

## Detect active blocking

Run `Active_Blocking.sql` to identify current blocking chains and waiting sessions.

## Review database/file growth

Run `DatabaseGrowth.sql` to understand current database file sizes and free space.
